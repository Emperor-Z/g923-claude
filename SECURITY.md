# Security policy

g923-claude injects keystrokes into the focused window, so security bugs matter here. Examples: a way for another local user to send input through the daemon's socket, or a way to make it type something you didn't choose.

Please **don't open a public issue**. Report it privately through [GitHub security advisories](https://github.com/Emperor-Z/g923-claude/security/advisories/new). You'll get a response within a few days.

Only the latest release is supported.
